# hükümdarlık çağı # Hükümdarlık Çağı

Tarihsel savaşların yaşandığı, çok oyunculu, açık dünya, birinci şahıs krallık strateji ve aksiyon oyunu.

## Özellikler
- Birinci şahıs kılıç ve ok dövüşü
- Çok oyunculu savaşlar
- Kendi krallığını kur ve yönet
- Açık dünya harita
- Hikâye modu (tek oyunculu kampanya)

## Yol Haritası
- [ ] Oyuncu hareketi ve kamera
- [ ] Kılıç dövüşü
- [ ] Çok oyunculu bağlantı (2-4 kişi)
- [ ] Küçük açık dünya haritası
- [ ] Krallık yönetimi (kasaba, ekonomi, ordu)
- [ ] Hikâye modu (3 bölüm)

- Oyun motoru: Godot 4 (veya Unity)
- Sürüm kontrolü: GitHub
